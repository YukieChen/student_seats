## 安裝和配置

### Q1: 系統支持哪些操作系統？

**A:** 系統支持以下操作系統：
- **Windows**: Windows 10 及以上版本
- **macOS**: macOS 10.14 (Mojave) 及以上版本
- **Linux**: Ubuntu 18.04 及以上版本

### Q2: 瀏覽器兼容性要求是什麼？

**A:** 支持的瀏覽器版本：
- **Chrome**: 80.0 及以上
- **Firefox**: 75.0 及以上
- **Safari**: 13.0 及以上
- **Edge**: 80.0 及以上

### Q3: 如何安裝系統？

**A:** 安裝方法：
1. **直接使用**: 下載系統文件，解壓後直接使用
2. **源代碼安裝**: 克隆代碼庫，安裝依賴後運行
3. **Docker安裝**: 使用Docker容器運行

詳細步驟請參考[安裝指南](User_Guide.md#安裝指南)。

### Q4: 系統需要多少內存和硬盤空間？

**A:** 系統要求：
- **內存**: 最少 4GB RAM，推薦 8GB RAM
- **硬盤**: 最少 100MB 可用空間
- **網絡**: 穩定的互聯網連接（用於更新和雲服務）

### Q5: 如何配置系統？

**A:** 配置步驟：
1. 編輯 `config/system.json` 文件
2. 設置算法參數和性能選項
3. 配置座位佈局和約束條件
4. 保存配置文件

詳細配置請參考[配置指南](User_Guide.md#配置指南)。

## 基本使用

### Q6: 如何創建新項目？

**A:** 創建項目步驟：
1. 點擊「新建項目」按鈕
2. 輸入項目名稱和描述
3. 選擇項目模板（可選）
4. 設置基本信息（班級名稱、年級等）
5. 點擊「保存」完成創建

### Q7: 如何導入學生數據？

**A:** 數據導入方法：
1. 準備數據文件（CSV、Excel、JSON格式）
2. 點擊「導入學生」按鈕
3. 選擇數據文件
4. 系統自動解析並驗證數據
5. 確認導入結果

### Q8: 支持哪些數據格式？

**A:** 支持的格式：
- **CSV**: 逗號分隔值文件
- **Excel**: .xlsx 和 .xls 文件
- **JSON**: JavaScript對象表示法
- **TXT**: 純文本文件（特定格式）

### Q9: 如何設置約束條件？

**A:** 約束設置：
1. **基本約束**: 座位偏好、鄰居限制、分組要求
2. **高級約束**: 特殊需求、成績分佈、行為管理
3. **約束權重**: 設置不同約束的重要性
4. **約束驗證**: 檢查約束衝突

### Q10: 如何執行座位分配？

**A:** 分配步驟：
1. 選擇算法類型（隨機、優化、高級）
2. 設置算法參數（迭代次數、超時時間等）
3. 點擊「開始分配」按鈕
4. 等待分配完成
5. 查看分配結果
