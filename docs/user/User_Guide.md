## 系統介紹

### 功能特點

- **智能分配**: 基於先進算法的智能座位分配
- **約束管理**: 靈活的約束條件設置
- **結果可視化**: 豐富的圖表和動畫展示
- **數據導出**: 支持多種格式的數據導出
- **性能優化**: 高效的算法和優化機制

### 系統要求

- **瀏覽器**: Chrome 80+, Firefox 75+, Safari 13+, Edge 80+
- **操作系統**: Windows 10+, macOS 10.14+, Linux (Ubuntu 18.04+)
- **內存**: 最少 4GB RAM，推薦 8GB RAM
- **存儲**: 最少 100MB 可用空間

## 安裝指南

### 方法一：直接使用（推薦）

1. **下載系統**
   - 訪問官方網站或下載頁面
   - 下載最新版本的系統文件

2. **解壓文件**
   ```bash
   # Windows
   右鍵點擊下載的文件 → 解壓到當前文件夾
   
   # macOS/Linux
   tar -xzf student_seats_system.tar.gz
   ```

3. **啟動系統**
   ```bash
   # 進入系統目錄
   cd student_seats_system
   
   # 啟動本地服務器
   python -m http.server 8000
   # 或使用 Node.js
   npx serve .
   ```

4. **訪問系統**
   - 打開瀏覽器
   - 訪問 `http://localhost:8000`

### 方法二：從源代碼安裝

1. **克隆代碼庫**
   ```bash
   git clone https://github.com/your-repo/student_seats.git
   cd student_seats
   ```

2. **安裝依賴**
   ```bash
   npm install
   # 或
   yarn install
   ```

3. **啟動開發服務器**
   ```bash
   npm start
   # 或
   yarn start
   ```

### 方法三：Docker 安裝

1. **拉取鏡像**
   ```bash
   docker pull student-seats:latest
   ```

2. **運行容器**
   ```bash
   docker run -p 8000:80 student-seats:latest
   ```

3. **訪問系統**
   - 打開瀏覽器
   - 訪問 `http://localhost:8000`

## 配置指南

### 基本配置

#### 1. 系統配置

在 `config/system.json` 文件中配置系統參數：

```json
{
  "engine": {
    "algorithm": "optimized",
    "maxIterations": 1000,
    "timeout": 30000
  },
  "display": {
    "theme": "light",
    "language": "zh-CN",
    "autoSave": true
  },
  "export": {
    "defaultFormat": "json",
    "autoDownload": true
  }
}
```

#### 2. 座位配置

在 `config/seats.json` 文件中配置座位佈局：

```json
{
  "classroom": {
    "rows": 8,
    "columns": 6,
    "aisles": [2, 4],
    "teacherDesk": {
      "row": 0,
      "column": 2
    }
  },
  "seats": {
    "size": "standard",
    "spacing": "normal",
    "orientation": "front"
  }
}
```

#### 3. 約束配置

在 `config/constraints.json` 文件中配置約束條件：

```json
{
  "preferences": {
    "enabled": true,
    "weight": 0.3
  },
  "restrictions": {
    "enabled": true,
    "weight": 0.7
  },
  "groups": {
    "enabled": true,
    "maxSize": 4
  }
}
```

## 操作指南

### 基本操作

#### 1. 創建新項目

1. **點擊「新建項目」**
   - 在系統主頁點擊「新建項目」按鈕
   - 輸入項目名稱和描述
   - 選擇項目模板（可選）

2. **配置基本信息**
   - 設置班級名稱
   - 選擇年級和學期
   - 設置學生人數

3. **保存項目**
   - 點擊「保存」按鈕
   - 項目將自動保存到本地

#### 2. 導入學生數據

1. **準備數據文件**
   - 支持 CSV、Excel、JSON 格式
   - 確保數據格式正確

2. **上傳文件**
   - 點擊「導入學生」按鈕
   - 選擇數據文件
   - 系統自動解析數據

3. **驗證數據**
   - 檢查導入的學生信息
   - 修正任何錯誤數據
   - 確認數據完整性

#### 3. 設置約束條件

1. **基本約束**
   - **座位偏好**: 學生對特定座位的偏好
   - **鄰居限制**: 某些學生不能相鄰
   - **分組要求**: 特定學生需要分組

2. **高級約束**
   - **特殊需求**: 殘疾學生的特殊安排
   - **成績分佈**: 按成績分佈座位
   - **行為管理**: 問題學生的座位安排

3. **約束權重**
   - 設置不同約束的重要性
   - 系統會根據權重進行優化

#### 4. 執行座位分配

1. **選擇算法**
   - **隨機算法**: 快速但結果可能不理想
   - **優化算法**: 平衡速度和質量
   - **高級算法**: 最佳結果但需要更多時間

2. **設置參數**
   - 最大迭代次數
   - 超時時間
   - 優化級別

3. **開始分配**
   - 點擊「開始分配」按鈕
   - 系統顯示進度條
   - 等待分配完成

#### 5. 查看和調整結果

1. **結果展示**
   - 座位安排圖表
   - 約束滿足情況
   - 性能統計信息

2. **手動調整**
   - 拖拽學生到不同座位
   - 系統自動檢查約束
   - 實時更新統計

3. **保存結果**
   - 點擊「保存」按鈕
   - 選擇保存位置
   - 添加備註信息

## 常見問題

### 1. 安裝問題

#### Q: 系統無法啟動怎麼辦？

**A:** 請檢查以下幾點：
1. 確認瀏覽器版本是否支持
2. 檢查防火牆設置
3. 確認端口是否被佔用
4. 查看錯誤日誌

#### Q: 如何更新系統？

**A:** 更新步驟：
1. 備份當前數據
2. 下載新版本
3. 替換舊文件
4. 重新啟動系統

### 2. 使用問題

#### Q: 分配結果不理想怎麼辦？

**A:** 可以嘗試以下方法：
1. 調整約束權重
2. 增加迭代次數
3. 使用高級算法
4. 手動調整結果

#### Q: 如何提高分配速度？

**A:** 優化建議：
1. 減少約束數量
2. 使用隨機算法
3. 啟用緩存功能
4. 關閉不必要的功能

### 3. 數據問題

#### Q: 數據導入失敗怎麼辦？

**A:** 檢查以下幾點：
1. 文件格式是否正確
2. 數據結構是否符合要求
3. 是否有重複或無效數據
4. 文件大小是否超限

#### Q: 如何備份數據？

**A:** 備份方法：
1. 導出項目數據
2. 備份配置文件
3. 保存用戶設置
4. 定期備份重要文件

### 4. 性能問題

#### Q: 系統運行緩慢怎麼辦？

**A:** 優化建議：
1. 關閉不必要的瀏覽器標籤
2. 清理瀏覽器緩存
3. 增加系統內存
4. 使用SSD硬盤

#### Q: 內存使用過高怎麼辦？

**A:** 解決方法：
1. 重啟系統
2. 清理緩存
3. 減少同時處理的數據量
4. 優化數據結構
